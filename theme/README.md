# CFF Evidence theme

`cff-evidence.css` is the reference token sheet for theme identifier
`cff-evidence/1.0.0`. Light values are the base declaration; dark values follow
`prefers-color-scheme`. The file also provides forced-colors, increased-contrast,
and reduced-motion adaptations.

Components consume semantic `--cf-*` tokens. Raw palette values belong only in
this token declaration, syntax themes, illustrations, and reviewed examples.
The brand gradient is decorative and must not carry text, status, focus, or
control meaning.
